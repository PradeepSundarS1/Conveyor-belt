# Conveyor Belt Automation System using ESP32

## Project Title
- Conveyor Belt Automation System using ESP32

---

## Abstract
- The Conveyor Belt Automation System is a simple industrial automation project developed using the ESP32 microcontroller.
- The system uses IR sensors to detect the presence of objects on the conveyor belt.
- When an object is detected, the ESP32 activates a DC motor through a motor driver to move the conveyor belt.
- A buzzer is also activated simultaneously to indicate object detection.
- When no object is detected, both the motor and buzzer automatically turn OFF.
- The project demonstrates basic industrial automation, object detection, and embedded control systems.

---

- Conveyor belt systems are widely used in industries for material handling and automation processes.

## Working Principle
- IR sensors continuously monitor object presence on the conveyor belt.
- ESP32 reads sensor signals in real-time.
- When an object is detected, the ESP32 sends control signals to the motor driver.
- The motor driver activates the DC motor to move the conveyor belt.
- The buzzer turns ON simultaneously to indicate object detection.
- When no object is detected, the motor and buzzer automatically turn OFF.
